## Description

CSC-221 is Introduction To Problem Solving and Programming in Python

For my penultimate assignment in CSC-221, I was tasked with creating a simple weather app. Create I did,

Using Requests and PyQT5, the weather app loads a 7-day forecast and a current location's conditions
for any named location or zip code provided by OpenWeatherMap's API

 ## Dependencies

 requests library
 PyQT5 library

 ## Other Requisites

 OpenWeatherMap API Key, set as an environment variable >>> https://home.openweathermap.org/api_keys
